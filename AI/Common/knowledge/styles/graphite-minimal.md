# Style: graphite-minimal

Near-black, hairline-bordered, small precise typography with a single subtle accent glow reserved for the primary action — the modern dev-tool/SaaS-dashboard dark aesthetic (Linear/Vercel/Raycast-adjacent), evolved with a glassmorphism surface treatment and a slow-drifting animated gradient background. A **UI/visual style only**.

## When to Apply
Invoke by name: "dùng style graphite-minimal". Governs markup structure, CSS, and layout — not JS/code conventions (those stay in `../../context/Conventions.md`).

## Visual Rules
- Base canvas near-black (`#0B0C0E`), kept **transparent at the `html/body` level** so a windowing layer (e.g. `NSVisualEffectView`) or the animated background can show through underneath everything.
- Surfaces are **glass, not solid**: low-alpha tint + strong blur — `background: rgba(20,23,30,.12)` (or `.22` for a "hi" variant), `backdrop-filter: saturate(240%) blur(18px)`. Alpha stays low specifically so the moving background is visible *and visibly moving* through the surface; blur is turned up to compensate so text stays legible.
- An **animated color-blob background** sits behind the glass: 2-3 large (~60vw) radial-gradient blobs in accent-adjacent hues, each on its own `translate3d`+`scale`+`opacity` keyframe loop (15-30s, `alternate`, `cubic-bezier(.4,0,.6,1)`), amplitude large enough to actually read as movement (a blob drifting only a few px over 20s is a bug, not subtlety). Add one continuous (non-alternating) slow `conic-gradient` "sheen" rotation (~30s linear) so motion never fully stops at a turnaround point, and a near-invisible (~3-4% opacity) SVG fractal-noise veil over the gradients to kill banding. Only animate `transform`/`opacity`; the resting frame must already equal a valid keyframe (never rely on `animation-fill-mode` to fix an `opacity:0` start).
- Separation between **content cards** and background comes from a **1px hairline border** (`rgba(255,255,255,.11)`, `.18` for a "hi"/hover variant) plus the glass surface above — not drop shadow. Default `box-shadow` is none beyond a faint `inset 0 1px 0 rgba(255,255,255,.04)` top highlight; reserve real shadow/glow entirely for the one interactive element that needs emphasis.
- Exception — **primary navigation tiles are flat, not glass**: `background: transparent`, hairline border only, plain neutral drop shadow (`0 10px 26px -10px rgba(0,0,0,.5)`), no blur. This is deliberate: tiles sit directly over the moving background with nothing dulling it, while secondary surfaces (cards, modals, settings panes, stat strips) get the blur treatment. Don't blur every surface uniformly — the flat/glass split is itself part of the style.
- Ink is a soft off-white (`#EDEEF0`), never pure `#FFFFFF`; secondary/muted text is a cool grey (`#8A8F98`).
- One accent color only (e.g. `#6C5CE7`), spent almost exclusively on the primary CTA and on small icon-tile badges (soft gradient fill + hairline-tinted border, e.g. `linear-gradient(180deg, rgba(accent,.18), rgba(accent,.07))` with `border:1px solid rgba(accent,.26)`) — everything else stays monochrome grey/white. This is the opposite of cyberpunk/vaporwave: restraint, not glow-everywhere.
- The primary CTA is the single place allowed a soft glow: `box-shadow:0 0 0 1px rgba(<accent>,.4), 0 0 16px rgba(<accent>,.35)` — no glow anywhere else on the page.
- Radius is small and consistent (8-9px base tokens for buttons/inputs, 10-13px for card/tile/modal containers) — never fully rounded/pill (except small status dots/chip indicators), never sharp 0px.
- Typography runs small (10-13px body) with tight, precise spacing (`letter-spacing: -.01em` to `-.03em` on headings) — reads as "information-dense tool", not "marketing page"; avoid large display type except a page-level title (~19-23px).
- Inputs match the surface convention: dark/glass fill, hairline border, no inner shadow, no native browser chrome — e.g. number inputs hide the native spin buttons entirely and pair with a custom **stepper**: one hairline pill containing a `−` button / borderless number input / `+` button, each side separated by an internal hairline. Checkboxes are also fully custom: `appearance:none`, 14px square with 4px radius, hairline border, accent fill + a hand-drawn check (rotated border trick) when checked — never the native checkbox/spinner look.
- All transitions are short and snappy: `90ms cubic-bezier(.2,.8,.2,1)`. Hover nudges border/background by exactly one hairline step (plain → `-hi` variant) and may lift an element `-1px` on Y; active/press states scale down slightly (`.92`-`.995`) for tactile feedback. Nothing eases slowly — this style has zero "soft cross-fade" moments.
- A settings/preferences surface follows the **macOS System Settings pattern**, not a Save/Cancel modal: fixed-size panel, left sidebar (~170px, icon+label rows, active row = accent gradient pill with no border) and a right content pane (page title + `settings-list`: a single hairline-bordered container of `settings-row`s, each row splitting a label+description on the left from a control — stepper/toggle/input — on the right, rows separated by internal hairlines only). No footer buttons: every change applies immediately, exactly like the real OS panel it mirrors.
- Multi-select filter pills ("chips") are a hairline pill with a small 5px currentColor dot indicator at low opacity; an "on" chip gets a filled `surface-hi` background + hairline-hi border and full-opacity dot; a destructive/heavy-selection variant recolors text+border to the danger red only while active.

## Source
Base aesthetic synthesized 2026-09-07 as generic modern dark dev-tool/SaaS-dashboard conventions. Re-captured with concrete evidence 2026-09-18 from the "Utilities" desktop app (pywebview), which explicitly declares this style in its stylesheet header — `Utilities/UI/style.css:1-473` (glass surfaces, animated blob background, tile/card flat-vs-glass split, stepper/checkbox controls) and `Utilities/UI/app.js:360-400` (Settings sidebar+list markup). This project's implementation is now the canonical reference; treat its CSS as the worked example when applying this style elsewhere.
