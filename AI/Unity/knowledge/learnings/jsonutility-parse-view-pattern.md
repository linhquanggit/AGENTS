# JsonUtility: base DTO chiếm field → parse qua class-view ngoài chuỗi kế thừa
Scope: DTO/JSON toàn project (JsonUtility)  |  Evidence: UIWorldBossLeaderBoard.cs:30-44, UIWorldBoss.cs (ConnectResponse : EventConnectResponse)

3 giới hạn JsonUtility: (1) không đa hình — object được tạo đúng kiểu field khai báo, field riêng của class con trong JSON bị vứt; (2) không remap tên key (không có [JsonProperty]); (3) không cho 2 field cùng tên trong chuỗi kế thừa (`new` shadow → Unity serializer "same field name is serialized multiple times", parse không tin cậy).
